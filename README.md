# EjerciciosJava

Soluciones de la práctica de Java organizadas en cinco proyectos y un menú para
abrir cada ejercicio.

## Contenido

Los proyectos y sus instrucciones están en [`ProyectosJava`](ProyectosJava/README.txt):

1. Cajero automático
2. Registro académico
3. Tienda online
4. Agenda de contactos
5. Sistema de notas con curva

El menú principal es `com.taller.menu.MenuTaller`. Para ejecutarlo, compila las
fuentes de los cinco ejercicios y del menú juntas, tal como se explica en la guía.
Se necesita el JDK de Java.
